💜 Meus Sites Favoritos

## Sobre o projeto
Este projeto foi desenvolvido como atividade prática de Desenvolvimento de Sistemas.

O objetivo é criar uma página web apresentando cinco dos meus sites favoritos, com imagens e links para acessá-los.

## Sites apresentados
- YouTube
- Google
- GitHub
- Canva
- ChatGPT

## Tecnologias utilizadas

- CSS3
